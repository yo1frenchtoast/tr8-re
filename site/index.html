Something went wrong?

    
The page refuses my file
Only the official system v1.61 is supported, unmodified. Download the zip again from Roland. A file already patched by this page is refused on purpose: always start from the official file.

    
The TR-8 does not start, or behaves badly
Hold step pad [1] while you switch on: the updater starts before the firmware, even a modified one. Install the official TR8_UPD.BIN, then restore your backup if needed.

    
The update stops with error 6
The file on the drive is not the one built here (checksum). Build it again, copy it again, and check that nothing else is on the drive.

    
Where are my motion moves or lengths after a restart?
The lengths are saved with each pattern. Motion moves stay in RAM for now: they are lost at power off.
